# Fullstack Test Task (CodeIgniter + Docker)

## Описание
Тестовое задание для Fullstack-разработчика.  
Необходимо разработать веб-приложение для управления списком комментариев с возможностью добавления, удаления, сортировки и постраничного просмотра.

---

## Технологический стек
- PHP 7.4  
- MySQL 8  
- CodeIgniter 4  
- jQuery 3  
- Bootstrap 4  
- Docker / Docker Compose  

---

## Установка и запуск

### 1. Предварительные требования
- Docker  
- Docker Compose  
- Для Windows: WSL (Windows Subsystem for Linux)

---

### 2. Запуск проекта
```bash
docker-compose up -d
```

---

### 3. Инициализация приложения
```bash
docker-compose exec web bash
composer install
```

---

## Функционал

### Комментарии
- name — email пользователя  
- text — текст комментария  
- date — дата создания  

---

## Требования

### Основной функционал
- Добавление комментариев (без перезагрузки желательно)
- Удаление комментариев
- Пагинация (3 комментария на страницу)
- Выбор страницы

### Сортировка
- ID
- Дата добавления

Направление:
- по возрастанию
- по убыванию

### Валидация
- Email на клиенте (jQuery)
- Email на сервере

### UI
- Адаптивная верстка
- Bootstrap 4
- jQuery 3
